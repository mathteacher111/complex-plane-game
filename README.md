# 복소수 좌표 게임

아이패드에서 사용할 수 있는 복소수 사칙연산 수업용 게임입니다.

## GitHub에 올릴 파일
이 폴더 안의 모든 파일을 GitHub 저장소에 올리세요.

## Vercel 배포
1. Vercel에서 GitHub 계정으로 로그인
2. Add New → Project
3. `complex-plane-game` 저장소 Import
4. Deploy 클릭

## 아이패드 사용
1. Vercel 주소를 Safari로 접속
2. 공유 버튼 → 홈 화면에 추가
3. 앱처럼 실행

## 오프라인
한 번 온라인으로 접속한 뒤에는 service worker 캐시로 오프라인 실행을 시도합니다.
단, 완전한 오프라인 보장을 위해서는 첫 접속 후 홈 화면에 추가한 다음 한 번 실행해 두는 것을 권장합니다.
